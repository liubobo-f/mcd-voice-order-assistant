# 专有名词等效词典

麦当劳点餐场景的标准词与用户常用同义表达对照表。SKILL.md 在理解用户输入时参考本表，把非标准表达**归一化为标准词**；用户不理解标准词时，用本表的「通俗解释」说明。

> 维护说明：本表增量维护——遇到新的同义表达，追加一行即可，无需改动 SKILL.md 主流程。

## 就餐方式

| 标准词 | 同义表达 | 通俗解释 |
|---|---|---|
| 得来速 | 车上取、开车窗口、汽车通道、drive-thru、不下车取 | 开车到专用窗口，不用下车就能点餐取餐 |
| 堂食 | 在店里吃、坐下吃、店内用餐、dine-in | 在餐厅里坐下吃 |
| 外带 | 带走、打包、拎走、自提、to-go | 点了带走，不在店里吃 |
| 麦乐送 | 外卖、配送、送到家、送上门、delivery | 送到指定地址 |

## 餐品（示例，以 query-meals 返回为准）

| 标准名 | 同义表达 |
|---|---|
| 巨无霸 | Big Mac、大麦克、双层牛肉堡 |
| 板烧鸡腿堡 | 板烧、烤鸡堡 |
| 麦辣鸡腿堡 | 麦辣、辣鸡堡 |
| 薯条 | 炸薯条、fries |
| 可乐 | 无糖可乐、零度可乐（用户指定无糖时对应） |

## 术语

| 标准词 | 同义表达 |
|---|---|
| 优惠券 | 券、优惠、折扣、满减 |
| 积分 | 麦麦积分、会员积分 |
| 取餐码 | 取餐号、取餐编号、订单号、报号 |

## 归一化规则

1. 优先匹配「同义表达」→ 归一到「标准词」。
2. 餐品名以 `query-meals` 实时返回为准，本表仅列高频示例。
3. 无法确定时，先复述理解、向用户确认，不臆测。
